# 0002 — Nome do produto

Status: aceito pelo mantenedor em 2026-09-24. Substituído pelo [ADR 0015](0015-memory-bee-identity.md) em 2026-09-24: o produto passa a se chamar Memory Bee.

## Decisão

Adotar **Memory Pier**, com slug `memory-pier`, substituindo o nome provisório Memory Share. A imagem de um píer representa a chegada e a passagem do contexto entre agentes, contas e pessoas.

## Contexto e limites

A pesquisa preliminar em GitHub e web encontrou colisões em nomes como Memory Share e Memory Bridge. Não foi encontrada colisão direta para Memory Pier nas buscas feitas; isso não constitui verificação de marca, domínio ou registro de pacotes.

O mantenedor autorizou publicar o repositório. Como não definiu a visibilidade, a criação inicial será privada na conta autenticada. A pasta local pode conservar o nome antigo sem alterar a identidade do produto.
